Customer Shopping Behavior Analysis
📌 Project Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI.
The main goal is to understand customer purchasing patterns, spending habits, product preferences, and sales trends through data analysis and visualization.

The project includes:

Data Cleaning using Python (Pandas & NumPy)
SQL Queries for business insights
Interactive Power BI Dashboard
Customer behavior analysis and reporting
📂 Project Files
customer_shopping_behavior.csv → Raw dataset
dap.ipynb → Python data analysis notebook
Customer_Behavior_Analysis.sql → SQL queries
